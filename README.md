# Windhoek Medical University — Official Website

This repository contains the source code for the official website of **Windhoek Medical University (WMU)**, a medical and allied-health training institution based in Windhoek, Namibia.

The site covers WMU's academic programmes (undergraduate, postgraduate, diploma and certificate), admissions and online application process, student support information, international partnerships, and general institutional information.

**Website:** [wmu.com.na](https://wmu.com.na)
**Address:** 165 Paul Van Harte Street, Khomas Grove Mall, Windhoek, Namibia
**Email:** info@wmu.com.na
**Phone:** +264 81 464 2621

## Tech Stack

- PHP (shared header/footer includes, programme data driven from a single source, online application handling)
- Plain HTML/CSS/JS — no framework or build step required

## Local Development

Requires a PHP-enabled web server (e.g. XAMPP/Apache). Point the document root at this folder and open `index.php`.
